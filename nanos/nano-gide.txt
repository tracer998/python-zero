1)Как в nano выделить и удалить весь текст или его большие участки,как в обычном редакторе?

В редакторе nano нет одной кнопки «Выделить всё» (как Ctrl+A в графических редакторах), но эту задачу можно быстро решить
комбинацией клавиш для навигации и работы с буфером. 

Как выделить и удалить весь текст
Чтобы удалить всё содержимое файла, выполните следующую последовательность действий:

Перейдите в начало файла: Нажмите Alt + \ (обратный слэш). 
Установите метку начала: Нажмите Ctrl + 6 (или Alt + A). В нижней части экрана появится индикатор «Mark Set». 
Перейдите в конец файла: Нажмите Alt + /. Весь текст между началом и концом файла выделится. 
Удалите выделенное: Нажмите Ctrl + K. Текст будет вырезан в буфер обмена. 

2)Удаление больших участков текста
Для работы с конкретными фрагментами используется тот же принцип ручного выделения:

Выделение: Установите курсор в начало нужного участка и нажмите Ctrl + 6 (или Alt + A). Затем переместите курсор стрелками к концу фрагмента.
Текст подсветится. 
Удаление: Нажмите Ctrl + K, чтобы вырезать выделенный блок. 
Вставка: Если вы удалили текст случайно или хотите переместить его, установите курсор в нужное место и нажмите Ctrl + U. 
3)Быстрые команды для очистки
Существуют более быстрые способы удаления текста без предварительного выделения:

Удаление от курсора до конца файла: Нажмите Alt + T. Эта команда мгновенно удалит весь текст, начиная от текущего положения курсора 
и до самого конца документа. 
Удаление текущей строки: Нажмите Ctrl + K. Если текст не выделен, эта комбинация удаляет строку, на которой стоит курсор. 
Повторное нажатие удалит следующую строку.

напиши полную инструкцию по остальным командам и чем они полезны

Вот полная инструкция по основным командам редактора nano, сгруппированная по назначению.

Навигация и управление курсором
Эффективное перемещение по файлу — основа быстрой работы.

Перемещение по строкам и словам: Используйте стрелки. Комбинация Ctrl + Стрелка влево/вправо перемещает 
курсор сразу на целое слово, а не на один символ.
Переход к началу/концу: Home (или Ctrl + A) переносит в начало текущей строки, End (или Ctrl + E) — в конец.
Переход к началу/концу файла: Alt + \ (начало файла) и Alt + / (конец файла).
Переход к конкретной строке: Нажмите Ctrl + _ (подчеркивание), введите номер строки и нажмите Enter. 
Это полезно для быстрого перехода к ошибке, указанной компилятором.

Работа с файлами (Сохранение и Выход)
Эти команды используются чаще всего для завершения работы.

Сохранить файл: Нажмите Ctrl + O (буква O, не ноль). Редактор спросит подтверждение имени файла. Нажмите Enter для подтверждения.
Выйти из редактора: Нажмите Ctrl + X. Если есть несохраненные изменения, nano предложит сохранить их перед выходом.
Сохранить как...: При нажатии Ctrl + O вы можете изменить имя файла перед подтверждением, чтобы сохранить копию под новым именем.
Поиск и Замена
Инструменты для работы с содержимым текста.

Поиск текста: Нажмите Ctrl + \ (или Ctrl + W в старых версиях). Введите искомую фразу. Курсор перейдет к первому совпадению. Для поиска следующего совпадения нажмите Alt + W.
Замена текста: Нажмите Ctrl + \. Введите искомый 
текст, затем текст замены. Редактор будет спрашивать подтверждение для каждой замены (Yes/No/All).

Буфер обмена и выделение
Управление выделенными фрагментами (копирование, вырезание, вставка).

Начать выделение: Ctrl + 6 (или Alt + A). Переместите курсор, чтобы выделить область.
Вырезать (удалить) выделенное: Ctrl + K. Текст сохраняется в буфере.
Вставить из буфера: Ctrl + U. Вставляет содержимое буфера в текущую позицию курсора.
Копировать выделенное: Alt + 6. Текст остается в файле, но копируется в буфер для вставки в другое место.
Отмена действий и помощь
Отменить последнее действие: Alt + U. Позволяет отменить удаление строки, вставку текста или случайное изменение.
 Можно нажимать несколько раз для отмены цепочки действий.
Справка: Нажмите Ctrl + G, чтобы открыть встроенное руководство со списком всех доступных команд.
